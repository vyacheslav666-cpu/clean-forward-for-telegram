# Участие в разработке

Спасибо за интерес к Clean Forward for Telegram. Проект экспериментальный: изменения должны оставаться небольшими, проверяемыми и безопасными для ручного сценария отправки.

## Перед началом

1. Проверьте существующие issues.
2. Для заметного изменения сначала создайте issue и опишите пользовательский сценарий.
3. Не включайте реальные сообщения, названия чатов, `peerId`, cookies, session data, browser profiles или снимки авторизованного Telegram.

## Локальная проверка

```bash
npm install
npm run validate
```

Добавляйте или обновляйте тесты для изменяемого поведения. Не ослабляйте правило ручного нажатия **Send** и не подключайте внешнюю передачу данных без отдельного обсуждения безопасности.

## Pull request

- ограничьте PR одной логической задачей;
- опишите мотивацию, поведение до и после изменения;
- отметьте выполненные проверки в шаблоне PR;
- обновите README или CHANGELOG, если меняется публичное поведение;
- убедитесь, что `npm run validate` проходит и `dist/clean-forward-for-telegram.user.js` собирается;
- не коммитьте `dist/`, source maps и локальные исследовательские артефакты.
